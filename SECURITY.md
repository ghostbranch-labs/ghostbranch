# Security Policy

Ghostbranch takes security seriously. As a tool designed to manage private development, secret scanning, and gated releases, we treat security vulnerabilities with high urgency.

## Supported Versions

Only the latest release receives security updates.

| Version | Supported |
|---|---|
| `0.1.x` | :white_check_mark: |
| Development builds | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, please report security issues through one of the following private channels:

1. **GitHub Private Vulnerability Reporting (Preferred):**
   Go to the [Security Advisories](https://github.com/ghostbranch-labs/ghostbranch/security/advisories/new) page on `ghostbranch-labs/ghostbranch` and click **"Report a vulnerability"**.

2. **Email:**
   Send details to **`ayush.gupta@tutamail.com`**.

### What to Include

Please provide:
- A description of the issue and its potential impact.
- Steps to reproduce or a minimal proof-of-concept repository.
- Ghostbranch version (`ghostbranch version`) and environment (OS, git version).
- Any details on whether private commit data, tokens, or repo state could be exposed.

### Response Timeline

- **Initial acknowledgment:** within 48 hours.
- **Assessment and updates:** we will keep you informed of our progress as we triage and develop a fix.
- **Coordinated disclosure:** we will coordinate the disclosure timeline with you once a patch is tested and ready for release.

Security advisories are published under [GitHub Security Advisories](https://github.com/ghostbranch-labs/ghostbranch/security/advisories).
