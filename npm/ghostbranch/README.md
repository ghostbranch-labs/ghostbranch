# ghostbranch

Private branches for public GitHub repos. Build unreleased features in a
private shadow of your open-source repo, running the same CI, and publish
them with one gated command.

```sh
npm install -g ghostbranch
ghostbranch login
```

This package holds a small launcher. npm installs the binary for your
platform from one of the `@ghostbranch/cli-*` packages, so keep optional
dependencies turned on.

Docs: https://ghostbranch.site · Source: https://github.com/ghostbranch-labs/ghostbranch
